# Privacy

This personal portfolio is intended to use privacy-friendly, aggregated analytics only.

Planned analytics may include page/section views, gateway progression, language and Pinyin selections, device category, browser/OS category, coarse country when available, and session-level engagement estimates.

The site is not intended to collect visitor names, email addresses, phone numbers, login identity, precise location, GPS data, or browser geolocation permission.

If a metric cannot be collected without protected or precise location access, that metric should be skipped rather than requesting location permission.
